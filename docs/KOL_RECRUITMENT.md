# KOL Recruitment & Marketing Approval (Master RCM v1.0)

โมดูลนี้อยู่ใน Wonder Courts เดิม (ไม่มีโปรเจกต์ / Repo / URL ใหม่) เมนู **KOL** ใน Rail ของระบบหลังบ้าน
ข้อมูลทั้งหมดอยู่ในฐานข้อมูล Wonder Courts (Neon) ของโปรเจกต์นี้เท่านั้น ไม่เชื่อมกับฐานข้อมูล PJAA

## Flow

1. KOL กรอก **ใบสมัคร** ที่ `/f/kol-apply` (หน้าเงื่อนไขแคมเปญ + ยอมรับเงื่อนไข) → ได้เลขอ้างอิง `KOL-0001` และลิงก์ติดตามสถานะ `/s/<token>`
2. **Marketing** คัดกรองที่ `/kol` → ดูรายละเอียด / บันทึกความเห็น / ขอข้อมูลเพิ่ม / ไม่ผ่านรอบคัดกรอง / ส่งให้ CEO (Marketing อนุมัติเองไม่ได้)
3. **CEO** ตัดสินใจบนการ์ดที่ `/kol/ceo` → อนุมัติ / ไม่อนุมัติ (ต้องมีเหตุผล) / ขอข้อมูลเพิ่ม — 1 คำขอตัดสินได้ครั้งเดียว (row lock + unique)
4. เมื่ออนุมัติ ระบบออก **ลิงก์ STEP 2** `/r/<token>` (อายุ 14 วัน) พร้อมข้อความสำหรับคัดลอกหรือเปิด LINE
5. KOL กรอก **ข้อมูล KOL/Influencers** (ถอดคำถามจาก Google Form STEP 2 เดิม) + เลือกวันเข้าสนาม → สถานะ `registered`
6. ทีมติดตามแคมเปญที่ `/kol/campaign` → นัดหมาย / ชิ้นงานที่ต้องส่ง / เครดิตสนาม / Promo Code

## Form Builder (`/kol/forms`)

- เพิ่ม / ลบ / แก้ / ทำสำเนา / ย้ายคำถาม, Section, เงื่อนไขแสดงคำถาม (อ้างอิงคำถามก่อนหน้าเท่านั้น), Field Mapping
- ร่างบันทึกอัตโนมัติ (`forms.draft`, `draft_rev` กันการเขียนทับ) → **เผยแพร่** สร้าง `form_versions` + `form_fields` ใหม่
- คำตอบเก่าผูกกับ `version_id` เดิมตลอด เปลี่ยนคำถามภายหลังไม่ทำให้คำตอบเก่าเปลี่ยน
- ดูคำตอบ / แก้คำตอบ (มีประวัติ `form_submission_edits`) / ส่งออก CSV (มี BOM + กันสูตร) หรือ XLSX

## ความปลอดภัยของหน้าสาธารณะ

- ลิงก์ token เก็บเฉพาะ SHA-256 hash; สำเนาเข้ารหัส AES-256-GCM (คีย์จาก `SESSION_SECRET`) ไว้ให้ทีมเปิดดูลิงก์ซ้ำ
- กันส่งซ้ำด้วย `client_key`, honeypot, timestamp ที่ลงลายเซ็น, rate limit ใน Postgres (`public_rate_events`)
- ไฟล์แนบตรวจ magic bytes, ≤ 10 MB, เก็บเป็น `bytea`; ไฟล์ที่ไม่ถูกผูกกับคำตอบใน 24 ชม. ถูกลบ

## การเก็บและลบข้อมูล

- ผู้มีสิทธิ์ `privacy.manage` ลบข้อมูลส่วนบุคคลของผู้สมัครได้จากหน้ารายละเอียด (พิมพ์ `ลบข้อมูล` เพื่อยืนยัน)
- สิ่งที่ถูกลบ: คำตอบในแบบฟอร์ม ไฟล์แนบ ประวัติการแก้คำตอบ บัญชีโซเชียล คอมเมนต์ เนื้อหาบันทึกรีวิว ชื่อ / เบอร์ / LINE / อีเมล / bio และลิงก์ทั้งหมดถูกยกเลิก
- สิ่งที่คงไว้: เลขอ้างอิง (`KOL-0001`), ประวัติสถานะ, ผลการตัดสินใจ, ตัวเลขแคมเปญ และ audit event `kol_applicant.erased` — เพื่อให้ยอดรวมของแคมเปญยังถูกต้อง

## ข้อจำกัดที่ยังไม่ได้เชื่อมระบบจริง

- **LINE**: ระบบเตรียมข้อความ + ปุ่มคัดลอก / เปิด LINE เท่านั้น ไม่ได้ส่งอัตโนมัติ
- **ระบบจองสนาม**: เครดิตสนามเป็นการบันทึกภายใน (`source = internal_tracking`) ไม่ได้หักเครดิตหรือจองสนามจริง
- **สถิติโซเชียล**: ยอดผู้ติดตาม / ยอดวิวเป็นตัวเลขที่ผู้สมัครหรือทีมกรอก ไม่ใช่ Real-Time API
- **Promo Code**: ยอดใช้งานอ่านจาก `bookings_imported` ที่นำเข้ามา ไม่ใช่ Real-Time
- **ภาพสนามจริง**: ยังไม่ได้รับไฟล์ต้นฉบับ หน้าแบบฟอร์มใช้ภาพประกอบ SVG และอัปโหลดภาพจริงได้ที่ Form Builder → ตั้งค่าฟอร์ม
- **ไฟล์**: เก็บใน Postgres เพราะโปรเจกต์ยังไม่มี Blob store
