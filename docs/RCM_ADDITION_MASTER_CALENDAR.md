# RCM Addition — Global Master Calendar (ปฏิทินกลาง)

รับจากเจ้าของระบบ 2 พ.ย. 2026 21:31 (Asia/Bangkok) — ข้อกำหนดเพิ่มเติมของ RCM v1.0

## ตำแหน่งและหลักการ
- เมนูหลัก "ปฏิทินกลาง (Calendar)" ลำดับที่ 2 ของแถบซ้าย ระดับเดียวกับ Dashboard เข้าถึงง่ายจากทุกอุปกรณ์
- แหล่งข้อมูล: Promotion, Campaign, Content, Task, CRM Follow-up, Inventory, Purchase Order, Event และ Manual Appointment
- ทุกโมดูลใช้รายการต้นทางเดียวกัน ไม่สร้างข้อมูลซ้ำ ปฏิทินแก้ไขรายการผ่านโมดูลเจ้าของข้อมูล และบันทึกประวัติการเปลี่ยนแปลง
- Filter: ประเภทงาน ผู้รับผิดชอบ สถานะ ช่วงเวลา และ "เฉพาะงานของฉัน"
- Responsive: PC แสดง Month/Week เต็มพื้นที่ · iPad ปรับจำนวนคอลัมน์ตามจอ · iPhone ใช้ Month แบบกะทัดรัดพร้อม Agenda ด้านล่าง
- Integration: เริ่มจากข้อมูลที่สร้างในเว็บและไฟล์ที่ได้รับอนุญาต ไม่เชื่อม LINE OA หรือระบบจองสนามเดิมโดยไม่ได้รับสิทธิ์
- Design: รักษาภาพ Master (พื้นขาว–ฟ้า เงาฟุ้ง การ์ดโปร่ง ชมพูเฉพาะจุดสำคัญ)
- หน้า S10 Content Calendar เป็นมุมมองย่อยของ Master Calendar

## A. Automatic Calendar Events
สร้างโปรโมชั่น → ช่วงเวลาแคมเปญขึ้นปฏิทินอัตโนมัติ แก้วันสิ้นสุด → ปฏิทินอัปเดตตาม (ไม่กรอกซ้ำ) เช่นเดียวกับคอนเทนต์ที่กำหนดวันเผยแพร่ งานที่มี Deadline และใบสั่งซื้อที่มีวันรับสินค้า

## B. Smart Alerts
โปรใกล้หมดอายุ · คอนเทนต์ถึงวันโพสต์แต่ยังไม่อนุมัติ · งานเลยกำหนด · ถึงกำหนดรับน้ำจากซัพพลายเออร์ — ผู้ใช้ตั้งค่าการแจ้งเตือนและผู้รับได้

## C. Calendar Conflict Detection
แสดงเมื่อรายการมีเวลาซ้อนกัน (เช่น นัดถ่ายคลิปกับประชุม) ตรวจจากปฏิทินที่ผู้ใช้มีสิทธิ์เห็น

## D. Weekly Workload Summary
จำนวนงานในสัปดาห์ งานเสร็จ งานเกินกำหนด งานรออนุมัติ และช่วงที่งานแน่น

## E. Quick Actions
จากรายการกดไปยังงานต้นทาง (โปร → หน้าคำนวณโปร, คอนเทนต์ → ไฟล์/แคปชัน, วันรับน้ำ → ใบสั่งซื้อ)

## ฟอร์ม "+ เพิ่มรายการ"
| ช่อง | หน้าที่ |
|---|---|
| ชื่อรายการ | เช่น ประชุมทีมการตลาด |
| ประเภท | โปรโมชั่น คอนเทนต์ นัดหมาย งานทั่วไป สต็อก |
| วันที่เริ่ม / สิ้นสุด | รองรับกิจกรรมข้ามวัน |
| เวลาเริ่ม / สิ้นสุด | Native Picker |
| ทั้งวัน | งานที่ไม่ระบุเวลา |
| ทำซ้ำ | รายวัน รายสัปดาห์ รายเดือน |
| ผู้รับผิดชอบ | สมาชิกทีม |
| สถานะ | วางแผน กำลังทำ เสร็จ ยกเลิก |
| แจ้งเตือน | ก่อนเริ่มตามระยะเวลาที่กำหนด |
| รายละเอียด/ไฟล์แนบ | หมายเหตุ ลิงก์ เอกสาร |
| ความเป็นส่วนตัว | ส่วนตัว ทีม ผู้บริหาร |

iPhone: ช่องวันที่และเวลาแยกบรรทัด ไม่ล้นจอ ไม่ซูมตอนกรอก

## มุมมอง 4 แบบ
- Month: ภาพรวมทั้งเดือน รายการหลายวันเป็นแถบต่อเนื่องจากวันเริ่มถึงวันสิ้นสุด
- Week: โพสต์อะไร ประชุมเมื่อไร Deadline วันไหน
- Day: ตารางรายชั่วโมง (ถ่ายทำ นัดหมาย งานประจำวัน)
- Agenda: ทุกรายการเรียงตามวัน พร้อมค้นหาและกรองหมวด

สี: Pastel badge เล็ก — ชมพู = โปร, ฟ้าอ่อน = คอนเทนต์, ม่วงอ่อน = นัดหมาย, เขียวอ่อน = สต็อก (ไม่ใช้สีทึบเต็มการ์ด)

## ข้อมูลที่ต้องแสดง
| ประเภท | ข้อมูล |
|---|---|
| โปรโมชั่น | วันเริ่ม–สิ้นสุด ระยะเวลา โปรใกล้หมดอายุ |
| แคมเปญการตลาด | ระยะเวลา วันเปิดตัว วันประเมินผล |
| แผนคอนเทนต์ | วันถ่ายทำ ออกแบบ ส่งอนุมัติ วันและเวลาโพสต์ FB / IG / TikTok |
| นัดหมายส่วนตัว/งาน | ประชุมผู้บริหาร นัดถ่ายคลิป นัดพาร์ตเนอร์ รายการที่เพิ่มเอง |
| งานและ Deadline | กำหนดส่งงาน วันตรวจงาน งานรออนุมัติ |
| สต็อกและการสั่งซื้อ | วันต้องสั่งน้ำ วันรับสินค้า วันตรวจนับสต็อก |
| กิจกรรมสนาม | Event, Tournament, ทดลองเล่น, Workshop |
| การรายงาน KPI | วันส่งรายงานรายสัปดาห์/เดือน วันสรุปผลโปรโมชั่น |
| นัดติดตามลูกค้า | วันที่ต้องติดต่อกลับ/ส่งรายละเอียด — เฉพาะผู้มีสิทธิ์ ไม่ดึงข้อความจาก LINE อัตโนมัติ |
